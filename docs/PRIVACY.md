## Сетевые запросы

Приложение не имеет сервера, аналитики, регистрации или сетевого клиента.
Классификация выполняется локально. GitHub, загрузка исходников и инструменты
сборки находятся вне runtime приложения.

## Что читается

- Список процессов, их аргументы, PID и рабочие папки для определения агента
  и привязки сессии.
- Открытые пути файлов через `lsof` при полной сверке.
- `~/.codex/sessions` и `~/.claude/projects` для служебных событий JSONL.
- Тип события, session ID, cwd и время из stdin lifecycle hook.
- Состояние питания, крышки и встроенного дисплея для включённых функций.

Transcript-reader читает фрагменты JSONL, которые могут включать текст запросов
и ответов. Классификатор использует служебные поля состояния; приложение
не создаёт копию истории переписки и не отправляет её наружу.
Это не означает, что процесс никогда не читает байты с содержимым сообщений.

## Что сохраняется

| Путь | Содержимое |
| :--- | :--- |
| `~/Library/Application Support/drem/state` | Состояние hooks: session ID, агент, cwd, PID при наличии, тип события и время. |
| UserDefaults домена `local.mrvasil.drem` | Выбранные режимы, оформление, горячая клавиша, флаги восстановления. |
| UserDefaults для восстановления дисплея | UUID встроенной панели и исходная яркость до затемнения. |
| Рядом с конфигами Codex/Claude | Резервные копии JSON-конфигурации, созданные установщиком. |
| `/etc/sudoers.d/drem-clamshell` | Только при настройке крышки: локальное разрешение двух команд pmset. |

Каталог состояния hooks создаётся с правами `0700`, его файлы с `0600`.
Резервные копии конфигурации могут содержать секреты из исходного файла:
храни их как конфиденциальные данные и не добавляй в Git.

При обновлении также читаются старый домен `local.mrvasil.AgentWatch` и
`~/Library/Application Support/AgentWatch/state`. Они не удаляются автоматически.
Старое правило `/etc/sudoers.d/agent-watch-clamshell` принимается для совместимости;
новая установка использует `/etc/sudoers.d/drem-clamshell`.

## Перед отправкой issue

`dremctl` выдаёт session ID, PID, имена проектов и timestamps.
Проверь и сократи вывод перед публикацией. Для большинства ошибок достаточно
версий macOS/агента, выбранных режимов и описания перехода состояния.

Не прикладывай raw transcripts, auth-файлы, окружение, токены, полный
`ps`-вывод или приватные пути. Если нужен пример события, замени идентификаторы,
cwd и содержимое на синтетические значения.
