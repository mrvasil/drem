# Privacy

[← drem](../README.md)

## Сетевые запросы

Приложение не имеет сервера, аналитики, регистрации или сетевого клиента.
Классификация выполняется локально. GitHub, загрузка исходников и инструменты
сборки находятся вне runtime приложения.

## Что читается

- Список процессов, их аргументы, PID и рабочие папки для определения агента
  и привязки сессии.
- Открытые пути файлов через `lsof` при полной сверке.
- `~/.claude/sessions/<pid>.json`: PID, session ID, платформа и время запуска;
  время сверяется с данными ядра, чтобы не перепутать повторно использованный PID.
- `~/.codex/sessions` и `~/.claude/projects` для служебных событий JSONL.
- `~/.codex/goals_1.sqlite`: только thread ID, статус и время обновления цели;
  текст `objective` не запрашивается.
- Тип события, session ID, cwd и время из stdin lifecycle hook.
- Сохранённые названия сессий: bounded tail `~/.codex/session_index.jsonl`,
  `session_title` Claude hook и записи `custom-title` из уже читаемого журнала.
  До 96 символов; первые запросы и тексты сжатия не используются как названия.
- Состояние питания, крышки и встроенного дисплея для включённых функций.
- Системный признак блокировки текущей CGSession для подтверждения режима «Вне дома».

Transcript-reader читает фрагменты JSONL, которые могут включать текст запросов
и ответов. Классификатор использует служебные поля состояния; приложение
не создаёт копию истории переписки и не отправляет её наружу.
Это не означает, что процесс никогда не читает байты с содержимым сообщений.

Для drem Island из тех же уже прочитанных событий извлекаются тип инструмента,
безопасное имя файла без полного пути и короткий фрагмент публичного сообщения
ассистента (до 240 символов). Эти сведения хранятся только в памяти; в hooks,
UserDefaults и вывод `dremctl` текст сообщений не записывается. Для Codex также
извлекается только короткий публичный заголовок summary, используемый индикатором
терминала (до 120 символов). Основной текст summary, raw reasoning/thinking,
аргументы команд, содержимое файлов и вывод инструментов
в модель острова не копируются. Публичное сообщение всё равно может содержать
секрет: автоматическая очистка секретов не обещается. Показ текста можно
отключить отдельно в настройках оформления.

Сигнал внимания извлекается только из структурированных событий: тип ожидания,
opaque ID вызова/исходного сообщения и время подтверждения. В памяти допускается
не больше 64 ожидающих ID, каждый до 256 UTF-8 байт. Содержимое вопросов, варианты
ответов и ответы не копируются в модель внимания. Для Claude hook дополнительно
читает `notification_type`, но не сохраняет текст уведомления. Ожидание разрешения
и его время сохраняются в hook-state; ID вопросов остаются только в памяти.

Положение указателя используется для наведения и пропуска кликов вне формы.
После ручного скрытия остаются только событийные обработчики клика и жеста
возврата возле чёлки: без опроса и наблюдения за движениями мыши. При блокировке,
закрытии крышки или отключении острова они тоже снимаются. Координаты и события
не записываются.

В системный локальный журнал macOS (`local.mrvasil.drem`, категория `Island`)
попадают только переходы видимости и причины запрета показа: например, закрытая
крышка, заблокированная сессия или отсутствие встроенного экрана с вырезом.
Тексты, пути, названия и идентификаторы сессий в этот журнал не записываются.

## Что сохраняется

| Путь | Содержимое |
| :--- | :--- |
| `~/Library/Application Support/drem/state` | Состояние hooks: session ID, агент, cwd, PID при наличии, тип события, время, режим возврата из сжатия, сохранённое название, подтверждённый тип ожидания и его время при наличии. |
| UserDefaults домена `local.mrvasil.drem` | Выбранные режимы, оформление, горячая клавиша, флаги восстановления. |
| UserDefaults для восстановления дисплея | UUID встроенной панели и исходная яркость до затемнения. |
| Рядом с конфигами Codex/Claude | Резервные копии JSON-конфигурации, созданные установщиком. |
| `/etc/sudoers.d/drem-clamshell` | Только при настройке крышки: локальное разрешение двух команд pmset. |

Каталог состояния hooks создаётся с правами `0700`, его файлы с `0600`.
Резервные копии конфигурации могут содержать секреты из исходного файла:
храни их как конфиденциальные данные и не добавляй в Git.

При обновлении также читаются старый домен `local.mrvasil.AgentWatch` и
`~/Library/Application Support/AgentWatch/state`. Они не удаляются автоматически.
Старое правило `/etc/sudoers.d/agent-watch-clamshell` принимается для совместимости;
новая установка использует `/etc/sudoers.d/drem-clamshell`.

Режим «Вне дома» не сохраняет пароль и не создаёт собственный экран входа.
Он динамически вызывает локальную системную функцию macOS; запасной путь может
использовать разрешение «Универсальный доступ» для штатного сочетания Lock Screen.
Эти действия не добавляют сетевых запросов.

Папка проекта открывается в Finder только явным нажатием. Её путь поступает
из уже отслеживаемой локальной сессии; дополнительных сканов для острова нет.
Копирование статуса выполняется только нажатием и учитывает переключатель
публичного текста. Диагностический CLI не выводит эти новые поля.

«К агенту» по явному нажатию читает PID, время старта, цепочку родителей и TTY
выбранного процесса через системный API, а затем TTY и идентификаторы панелей
поддерживаемого терминала через AppleScript. Время запуска фиксируется при
первой привязке строки острова, чтобы отклонить повторно использованный PID.
Новый фоновый опрос не добавляется. Содержимое терминала, окружение и названия
вкладок для перехода не читаются, клавиши и команды агенту не отправляются.
macOS может запросить разрешение «Автоматизация» для управления терминалом.
Отказ не обходится; неподдерживаемые версии Ghostty не переключаются наугад.

## Перед отправкой issue

`dremctl` выдаёт session ID, PID, имена проектов и timestamps.
Проверь и сократи вывод перед публикацией. Для большинства ошибок достаточно
версий macOS/агента, выбранных режимов и описания перехода состояния.

Не прикладывай raw transcripts, auth-файлы, окружение, токены, полный
`ps`-вывод или приватные пути. Если нужен пример события, замени идентификаторы,
cwd и содержимое на синтетические значения.
