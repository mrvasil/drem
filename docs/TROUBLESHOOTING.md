# Troubleshooting

[← drem](../README.md)

## Агент работает, а статус не обновился

1. Нажми «Обновить агентов».
2. Проверь, что агент работает локально, а журналы находятся в стандартном
   каталоге. Агент внутри удалённой VM или SSH-сессии не становится локальным
   процессом macOS.
3. После установки hooks открой новую сессию. В Codex проверь `/hooks`,
   если запрошено подтверждение.
4. Для локальной диагностики запусти `swift run dremctl` из репозитория.

Проверка CLI выдаёт метаданные сессий и проектов. Не публикуй вывод целиком
без редактирования. Если формат агента изменился, приложи минимальный
синтетический пример служебных событий, а не всю переписку.

## Mac не засыпает после последней задачи

Сначала проверь, что включён именно режим «Пока работают агенты»,
а не бессрочный ручной сеанс. Приложение снимает свои блокировки, но
не вызывает принудительный сон.

Посмотреть владельцев assertions можно без изменения настроек:

```sh
pmset -g assertions
pmset -g
```

Другие приложения, активный дисплей или системные таймеры могут задерживать сон.
Выход из drem не останавливает чужие блокировки.

## Force-quit оставил запрет сна

Запусти drem заново и заверши его штатно. При старте он проверяет
оставшееся состояние и пытается вернуть обычную политику сна.

Если приложение невозможно запустить, после проверки вывода `pmset -g`
можно вручную снять системный `SleepDisabled`:

```sh
sudo /usr/bin/pmset disablesleep 0
```

Это меняет системный режим. Убедись, что другой keep-awake инструмент сейчас
не использует его намеренно. Команда не удаляет настройки питания или данные.

## Экран остался тёмным

Открой крышку и перезапусти приложение для восстановления сохранённой яркости.
Можно поднять её клавишами Mac. Не удаляй recovery-настройки до восстановления.

DisplayServices может быть недоступен после обновления macOS или на конкретной
модели. Приложение сообщает ошибку вместо затемнения без сохранённого значения.
Физические сценарии крышки нельзя полностью проверить в hosted CI.

## Сборка или тесты

```sh
swift --version
xcode-select -p
make check
make test
```

Тестовый runner требует Swift 6+ и macOS 14+, хотя приложение имеет deployment
target macOS 13. При Command Line Tools используй `make test`, а не голый
`swift test`: wrapper добавляет пути к Testing.framework.

Предупреждение linker о Testing.framework для macOS 14 при target 13 относится
к тестовому runner, не доказывает сбой приложения на macOS 13.
Совместимость с каждой моделью Mac и каждым релизом системы не гарантируется.

## Два значка в строке меню

Заверши лишний экземпляр. `make run` открывает сборку из `dist`, а
`make install` открывает установленную копию. Не запускай их одновременно.
