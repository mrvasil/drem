# Режимы сна и иконка

[← drem](../README.md)

## Пока работают агенты

На главной панели включи «Не давать Mac уснуть» и «Пока работают агенты».
При первой настройке режим попросит разрешение управлять сном при закрытой крышке.

| Событие | Результат |
| :--- | :--- |
| Началась задача | Включается удержание сна. |
| Один агент закончил, другой работает | Удержание продолжается. |
| Последняя задача закончилась | Снимаются все блокировки приложения. |
| Все CLI открыты, но ждут ввод | Mac может спать. |
| Главный выключатель выключен вручную | Текущий сеанс остановлен до сброса условий автоматизации. |
| Достигнут порог батареи | Удержание прекращается ради защиты батареи. |

Режим агентов имеет приоритет над ручным таймером, автозапуском удержания,
питанием и внешним дисплеем. При включении он забирает управление существующим
ручным сеансом и отменяет его таймер. После завершения работы прежний ручной
сеанс не возвращается.

Пауза на заблокированном экране не прерывает агентный режим.
Чтобы снова разрешить запуск после ручной остановки, дождись завершения задач
либо выключи и включи агентный режим.

Остановка удержания не отправляет Mac принудительную команду сна.
macOS учитывает свои таймеры, состояние крышки и блокировки других приложений.

## Крышка и яркость

Когда агентный сеанс и удержание сна активны, закрытие крышки затемняет только
встроенный дисплей. Исходные яркость и UUID панели записываются до затемнения.
При открытии возвращается прежнее значение; внешние дисплеи не меняются.

Если задачи закончились с закрытой крышкой, экран остаётся тёмным до открытия,
но восстановление яркости не продлевает блокировку сна. При штатном выходе
приложение восстанавливает яркость. После сбоя это возможно только при следующем
запуске; клавиши яркости остаются ручным способом восстановления.

Разрешение крышки ограничено двумя командами `pmset disablesleep 0/1`.
Это системный переключатель, а не приватная per-app assertion: другие приложения
могут конфликтовать с ним. Не управляй тем же режимом одновременно из нескольких
утилит.

DisplayServices загружается динамически и не является стабильным публичным API.
На неподдерживаемой системе функция может быть недоступна. Не считай закрытый
Mac выключенным; обеспечь вентиляцию.

## Ручное удержание

С выключенным режимом агентов доступны:

- бессрочный сеанс или 15, 30, 60, 120, 240, 480 минут;
- продление активного таймера на 15, 30 или 60 минут;
- автоматическое включение при питании или внешнем дисплее;
- разрешение сна дисплея отдельно от сна системы;
- пауза при блокировке экрана;
- отключение при выбранном заряде;
- необязательное движение указателя;
- глобальная клавиша `⌃⌥⌘K` по умолчанию.

Все дополнительные параметры находятся в «Настройки…» (`⌘,`).
Автоматическое включение при запуске drem не означает запуск приложения
при входе в macOS.

## Правило иконки

| Блокировщик | Иконка |
| :--- | :--- |
| Выключен | Всегда одна монохромная звезда. |
| Включён, выбран «drem» | Та же звезда выбранного цвета. |
| Включён, выбран другой символ | Выбранный системный символ и цвет. |

«Системный» оставляет активную иконку монохромной. «Оранжевый» использует
сохранённый оттенок батареи `#F8D849`. Работающие агенты не переопределяют
оформление напрямую. Счётчик рядом отражает их число независимо от выбора символа.

## Статусы

**Работает** означает выполняемый ход; **Ожидает** означает открытый CLI без
активного хода; **Не запущен** означает отсутствие обнаруженного процесса.

Приложение получает статус из hooks и локальных журналов, а не измеряет CPU.
Свежий процесс без подтверждения задачи не считается работой. Общий host-процесс,
неоднозначные сессии и изменённые форматы журналов ограничивают наблюдаемость.
При сомнении нажми «Обновить агентов» и сверь состояние с самим агентом.
