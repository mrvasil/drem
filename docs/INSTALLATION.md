# Установка

[← drem](../README.md)

## Требования

| Компонент | Требование |
| :--- | :--- |
| Приложение | macOS 13 или новее |
| Сборка и тесты | Swift 6+, Xcode или Command Line Tools; тесты на macOS 14+ |
| Установщик hooks | Python 3.10+ |
| Агенты | Локальный Codex или Claude Code с обычными каталогами журналов |
| Закрытая крышка | MacBook и одноразовое разрешение администратора |
| Сборка для другой архитектуры | Отдельный Apple Silicon / Intel runner или соответствующая cross-сборка |

В пакете нет сторонних Swift-зависимостей. Поддержка событий агентов зависит
от их версии. Детектор работает с текущими локальными форматами, но новые форматы
могут потребовать обновления.

## Из исходников

```sh
xcode-select --install
git clone https://github.com/mrvasil/drem.git
cd drem
make install
```

Если исходники уже скачаны, достаточно `make install` из корня проекта.
Для приватного GitHub-репозитория нужен доступ к нему и настроенная авторизация Git.

Установщик:

1. Собирает release-конфигурацию и Retina-иконки.
2. Создаёт ad-hoc подписанный `dist/drem.app`.
3. Копирует приложение в `~/Applications/drem.app`.
4. Добавляет lifecycle hooks в `~/.codex/hooks.json` и `~/.claude/settings.json`.
5. Запускает приложение.

Существующие настройки сохраняются. Перед каждой записью конфигурации
установщик создаёт копию вида `hooks.json.drem-backup-<timestamp>`.
Запись атомарная; новые файлы конфигурации имеют права `0600`.
Установка двух конфигов не является одной транзакцией: если второй файл
некорректен, первый уже может быть обновлён. Исправь JSON и повтори установку.

## Без изменений конфигурации агентов

```sh
make build
open "dist/drem.app"
```

Или одной командой: `make run`. Приложение использует локальные журналы.
Не запускай одновременно установленную копию и копию из `dist`.

## Обновление

Заверши работающий drem обычной командой выхода из его меню.
Это освобождает блокировки сна и восстанавливает яркость, если приложение
ею управляло. Затем:

```sh
git pull --ff-only
make install
```

После обновления с Agent Watch новый домен настроек `local.mrvasil.drem`
однократно импортирует прежние значения. Существующие настройки drem имеют
приоритет; старый домен не удаляется и остаётся резервной копией.
Сохранённые данные восстановления яркости и сна также переносятся.

## Hooks

| Агент | События установщика |
| :--- | :--- |
| Codex | `SessionStart`, `UserPromptSubmit`, `Stop`, `Interrupt`, `SessionEnd` |
| Claude Code | `SessionStart`, `UserPromptSubmit`, `Stop`, `StopFailure`, `SessionEnd` |

Это список записей нашего установщика, а не гарантия наличия каждого события
во всех версиях агента. В Codex проверь `/hooks`, если требуется доверие.
Уже открытая сессия может продолжить работу через fallback; для применения
обновлённых hooks иногда нужен новый запуск агента.

## Артефакты CI

В успешном запуске [CI](https://github.com/mrvasil/drem/actions/workflows/ci.yml)
доступен ZIP для каждой проверенной архитектуры. Внутри находится
`drem.app`, файлы лицензии и атрибуции.

Эти сборки предназначены для проверки. Они не notarized и не подписаны
сертификатом Developer ID. Для повседневной установки предпочтительна сборка
из проверенных исходников. Не отключай Gatekeeper целиком ради запуска.

## Удаление

1. Заверши приложение через его меню. После force-quit сначала запусти его
   снова для восстановления сна и яркости, затем выйди штатно.
2. В двух JSON-конфигах выше удали только обработчики, чья команда запускает
   `/drem.app/Contents/MacOS/drem-hook`. Сохрани чужие hooks
   и остальные настройки. Не восстанавливай старый backup поверх более новых
   изменений без сравнения.
3. Перемести `~/Applications/drem.app` в Корзину.
   Если сохранилась старая копия Agent Watch, заверши и удали её отдельно.
4. При необходимости удали локальные данные, перечисленные в
   [Privacy](PRIVACY.md), предварительно убедившись, что восстановление завершено.

Если настраивалось разрешение крышки, после завершения приложения и восстановления
`SleepDisabled 0` администратор может удалить только правило
`/etc/sudoers.d/drem-clamshell`. Остальные системные правила не меняй.
После обновления со старой версии правило может называться
`/etc/sudoers.d/agent-watch-clamshell`.
Удаление приложения само по себе не удаляет это разрешение.
