**drem** живёт в строке меню macOS, отслеживает работу Codex и Claude Code
и удерживает Mac от сна на время их задач. Открытый терминал сам по себе
не включает блокировщик.

Приложение написано на SwiftUI и AppKit. Нет аккаунта, облачного сервиса,
аналитики или сторонних зависимостей пакета.

Интерфейс пока на русском. При обновлении с Agent Watch настройки сна,
оформления и восстановления переносятся автоматически; новые hooks заменяют
старые обработчики без изменения чужих настроек.

## Пока ты занят другим

| Возможность | Что происходит |
| :--- | :--- |
| Статус агентов | Видно, кто выполняет задачу, кто ждёт команду, а кто не запущен. |
| Сон по задачам | Хотя бы один агент работает → удержание сна. Последний закончил → все блокировки приложения сняты. |
| Закрытая крышка | Отдельное разрешение позволяет продолжать работу с закрытым ноутбуком. |
| Тёмный встроенный экран | При закрытии яркость снижается до нуля, при открытии возвращается прежняя. |
| Ручной режим | Бессрочное удержание или таймер, продление сеанса, горячая клавиша и порог заряда. |
| Спокойная строка меню | Монохромная звезда при выключенном блокировщике; выбранный символ и цвет при включённом. |

Счётчик рядом с иконкой показывает число работающих сессий.
При выборе «drem» активной иконкой остаётся та же звезда.
Настройки цвета работают для всех активных символов.

## Установка

Нужны macOS 13+, Git, Python 3 и инструменты разработчика Apple со Swift 6+.
Для запуска тестов нужна macOS 14+. Подойдут актуальные Xcode или Command Line Tools:

```sh
xcode-select --install
```

Затем:

```sh
git clone https://github.com/mrvasil/drem.git
cd drem
make install
```

Если репозиторий приватный, сначала авторизуй Git или используй
`gh repo clone mrvasil/drem`.

Команда собирает и локально подписывает `drem.app`, помещает его
в `~/Applications`, устанавливает lifecycle hooks для Codex и Claude Code
и запускает приложение. Перед изменением существующих JSON-конфигов
создаются резервные копии; посторонние hooks сохраняются.

В Codex проверь новые hooks через `/hooks`, если твоя версия требует
подтверждения. До этого приложение использует локальные журналы как резервный
источник. Подробности и удаление: [Installation](docs/INSTALLATION.md).

<details>
<summary>Собрать или попробовать без установки hooks</summary>

```sh
make build   # dist/drem.app
make run     # собрать и открыть без изменения конфигов агентов
make test    # самопроверки и автоматические тесты
```

Сборка создаётся для архитектуры текущего Mac. Для распространения между
Apple Silicon и Intel нужны соответствующие сборки. Локальная ad-hoc подпись
не является Developer ID подписью или notarization.

</details>

## Два переключателя

Чтобы ноутбук продолжал задачи даже с закрытой крышкой:

1. Включи **«Не давать Mac уснуть»**.
2. Включи **«Пока работают агенты»**. При первой настройке разреши управление
   сном при закрытии крышки в системном запросе.

После последней задачи приложение снимает свои блокировки сна системы,
дисплея и крышки, останавливает движение указателя. Агентный режим остаётся
включённым и ждёт следующей задачи.

**Это возврат к обычной политике сна macOS, а не принудительное усыпление.**
Другие приложения могут продолжать удерживать Mac от сна. Защита по заряду
батареи также может остановить удержание.

[Все режимы, приоритеты и восстановление →](docs/USAGE.md)

> [!CAUTION]
> Держи работающий закрытый ноутбук на открытой твёрдой поверхности.
> Не убирай его в сумку. При аварийном завершении приложения системный запрет
> сна может сохраниться до перезапуска или ручного восстановления.
> [Ограничения и восстановление](docs/TROUBLESHOOTING.md).

## Тихо в фоне

Основной путь событийный: hooks и уведомления файловой системы сообщают
о начале и конце задач. Привязка к сессии и процессу помогает обработать
закрытие вкладки без завершающего hook.

Журналы читаются по приращению. Каждые 15 секунд проверяются известные PID
и изменения привязанных файлов; полный поиск остаётся для старта, ручного
обновления, восстановления и пятиминутной сверки. Секундного полного сканирования
и анимаций в строке меню нет.

[Архитектура и границы детектора →](docs/ARCHITECTURE.md)

## Данные остаются на Mac

Для классификации читаются локальные процессы, служебные поля журналов
Codex/Claude и lifecycle-события. Hooks сохраняют состояние сессии, рабочую папку,
идентификаторы и время. Приложение не отправляет эти данные по сети.

Файлы журналов могут содержать запросы, ответы и секреты. Даже если интерфейс
показывает только статус, не прикладывай исходные журналы к issue.
[Что читается и сохраняется](docs/PRIVACY.md).
